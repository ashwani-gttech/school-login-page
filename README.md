# School Login Page

This project is a colorful Python login page for school kids.

## How to run

1. Open a terminal in the project folder.
2. Run:

```bash
python login_page.py
```

## Login details

- Username: student
- Password: school123

## Features

- Kid-friendly school theme
- Easy-to-read labels and buttons
- Password field hidden with stars
- Success and error message pop-ups
- Built with Python Tkinter

## Notes

Tkinter comes included with many Python installations on Windows and macOS. If it is missing, install Python from python.org and make sure the Tkinter option is included.
